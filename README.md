### My contribution

I authored the initial OpenAPI specification with limited AI assistance. I later expanded and corrected the documentation and validation workflow with AI assistance. I reviewed rendered examples in Swagger Editor, checked navigation and formatting, and confirmed successful GitHub Actions runs.

### Scope and validation

FlowSync is a documentation demonstration, not a live product. Its backend and dashboard are not implemented. The examples describe an intended API contract and have not been tested against a running service.

Automated checks examine the specification; they do not establish runtime behavior or documentation usability. See the [project README](https://github.com/sinsane-jpg/flowsync-api-documentation#validation) for validation details and limitations.
